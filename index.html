AI / ML PROJECT

Lightweight ViT Object Detection Research

ViT · Computer Vision

01

PROJECT

Project Overview

This project focused on addressing the challenges of traditional object detection models, including large model size, slow inference speed, high deployment costs on embedded devices, and the difficulty of balancing detection accuracy with efficiency.

Based on a lightweight Vision Transformer (ViT) architecture, the project developed an efficient object detection model for edge-side deployment. The Vision Transformer architecture was optimized through structural pruning, parameter reduction, and feature fusion improvements to reduce computational cost and model complexity.

The project also incorporated dataset augmentation, hyperparameter tuning, and comparative experiments to improve model performance. The final approach aimed to maintain strong detection accuracy while improving inference efficiency, making it suitable for real-time object detection on mobile and embedded devices.

02

PROJECT

My Role

Data Preparation & Lightweight ViT Architecture Research

I was responsible for dataset cleaning, annotation verification, and data augmentation to improve sample quality and distribution, helping enhance training stability and model generalization.

I also studied the structure of lightweight Vision Transformer backbones and contributed to simplifying and modifying traditional Transformer modules to reduce the number of model parameters and computational overhead.

03

PROJECT

Result

Result

Lightweight ViT Object Detection Model

The project applied knowledge distillation, iterative pruning, INT8 quantization, and TensorRT optimization to improve the efficiency of the lightweight object detection model. On the COCO-80 dataset, the best-performing model achieved an mAP@0.5 of 0.752. INT8 quantization reduced the model size from 22.1 MB to 5.8 MB, representing a 74% reduction in model size. After the combined optimization, overall inference speed increased by 5.5×, with an inference latency of 8 ms. The optimized model maintained strong detection accuracy with only a small decrease in overall precision, meeting the requirements for real-time object detection on edge devices.
